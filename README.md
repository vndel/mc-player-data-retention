# Minecraft Player Data Retention

Policy templates for minimizing retention of player-related operational data. Adapt them to applicable privacy law, platform terms, and your documented service purpose; this repository is not legal advice.

## Retention principles
- Collect only fields required for a defined operational purpose.
- Set an owner and deletion period for each data class.
- Separate security audit records from gameplay analytics and chat content.
- Apply deletion to primary stores, exports, and scheduled backup expiry where feasible.
- Restrict access and record administrative access to sensitive datasets.
- Document exceptions, legal holds, and deletion verification.

Review the policy when data sources or service purposes change. Never publish real player records in examples.
